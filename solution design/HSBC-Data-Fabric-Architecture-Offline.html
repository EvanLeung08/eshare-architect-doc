02 / ARCHITECTURE GUARDRAILS

Key Architecture Guardrails

Clear ownership, recoverable failures, and a single, complete file hand-off to downstream consumers.

01

Product-level isolation

Each Data Product has independent SQL, channel, schedule, watermark, schema, and landing-folder configuration.

02

Safe file hand-off

Adapters publish only complete files and manifests. AIP Core scans folders containing _SUCCESS, preventing partial-file reads.

03

Recoverable by design

Retryable failures recover automatically. Non-retryable failures move to the DLQ with alerts and can be safely replayed using the original Run ID after remediation.

04

Routing stays in AIP

Adapters remain unaware of downstream routes. AIP Core uses its existing configuration for 1:N distribution, avoiding duplicate routing logic.
